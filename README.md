# Dust

[![codecov](https://codecov.io/gh/mashu/dust/graph/badge.svg)](https://codecov.io/gh/mashu/dust)
[![Pages](https://github.com/mashu/dust/actions/workflows/pages.yml/badge.svg)](https://mashu.github.io/dust/)
[![License: GPL v3](https://img.shields.io/badge/license-GPLv3-blue.svg)](LICENSE)

CW Morse **group trainer** in Rust. Hear a group, type it from memory, and get
alignment-based accuracy, letter mastery and a score — and a **score board** of
your best sessions, with a medal for the personal best.

Two ways to practise: Koch-style **character groups**, unlocked one letter at a
time, or **callsigns** — real prefixes in realistic shapes, from `W1AW` up to
`DL1ABC/P` and `EA8/G3XYZ`, the drill MorseRunner and Morse Walker are built
around. Every call is one its country could issue: prefixes, the digits after
them and the lengths of their suffixes come up as often as they do in real
calls, counted from the Super Check Partial list of active contest calls by
`scripts/callsign-prefixes.py`.

Opt in to **adaptive group size** and the trainer learns your copy span, the
group length you copy whole about half the time, and draws lengths near its
edge: longer while you copy groups whole, shorter when you don't
([how it works](docs/adaptive-group-size.md)).

New here? A guided setup opens on the first launch, and the **?** in the
header opens it again any time. It takes you through a first session — start
one, copy a group, discard it — and then the settings that matter most:
unlock order, speed, group size, pitch and auto level. It points at the
control to press for each and ticks it off once you have, or press
**Show me** and watch it done for you.

Or start from a preset: **Settings → Experience** sets session length, group
size and speed for a Novice, Intermediate, Advanced or Expert in one go —
your level stays yours — and shows Custom once you change any of them.

Answer on the screen's own keypad: large keys for every letter, digit and
sign a group can hold, in one layout for the whole session, so a phone's
keyboard never comes and goes over the groups. Only the group you are
copying and the one before it are on screen, the one before dimmed with how
it went. A session counts down before its first group (3 seconds unless you
set otherwise under **Session shape**), and keeps the screen on until it
ends. Take your time over an answer: the answer timeout moves on only from a
group you have not started, and one you have waits until every character is
in or you press **Next**.

The **score** works the way RufzXP's does: each group earns points with the
square of its speed and in proportion to its length; every error cuts what is
left hard — one to a quarter, two to a ninth — a group sent again earns half,
and a slow answer costs a little, a quarter for each tenfold past a tenth of a
second a character. Two things are Dust's own: a character from a short Koch
alphabet is worth what it tells you (`log₂` of how many it could have been,
against the 26 letters), and Farnsworth spacing earns between its two speeds.
Your history is scored the same way, sessions from before included.

Practise words of your own: pick **Words** under Character set and paste a
list, one word to a line, or load it from a text file. Each word is sent
whole, and the ones holding the characters you miss come round more often.
Until you add a list, Words sends the abbreviations and Q-codes of a contact.

**[Try it in the browser →](https://mashu.github.io/dust/)**

## Platforms

One codebase, one feature per target. Audio is the same plan everywhere: same
keying envelope, same random tone and speed per group, same QSB, and the same
band — generated by one model in Rust on every platform.

The band is built the way a receiver hears it. Gaussian band noise,
atmospheric static (the crackle of distant storms, and the multi-stroke
crashes of a near one) and the other stations on the band go through one
eight-pole CW filter together with the Morse, so the hiss takes the filter's
pitch and every crash and dit rings in it; the AGC ducks the band under a
strong station and behind a crash, and the audio stage after the filter adds
its own floor, far enough under the hiss that a narrow filter leaves no
wideband noise to hear. The filter is set by its width at −6 dB and one of three
shapes: **Sharp** (a modern DSP filter, flat with steep sides), **Soft**
(rounded, like an older crystal filter) and **Peaked**, the default: Sharp
plus the rig's audio peak filter, which rings at your pitch. "Stations
calling at once" sets how many call across the one you copy, and the band
carries its own traffic between groups.

## Develop

```bash
curl -sSL https://dioxus.dev/install.sh | bash   # once

dx serve --platform desktop          # system webview
dx serve --platform web --port 8080
```

Desktop is a WebKit/WebView2 window. The Linux build needs ALSA and WebKitGTK:

```bash
sudo apt install libasound2-dev libwebkit2gtk-4.1-dev libgtk-3-dev \
  libayatana-appindicator3-dev librsvg2-dev
```

## Test

```bash
cargo test -p cw-core                    # domain logic
cargo test -p dust --features desktop    # app, audio and UI
```

Sessions run for real: a paused clock drives the true sends, gaps, timeouts and
auto-confirms in milliseconds, screens are tested by pressing their buttons, and
a recording player stands in for the sound card. The cpal backend opens the
machine's real output; where there is none, an ALSA null device stands in:

```bash
printf 'pcm.!default { type null }\nctl.!default { type null }\n' > ~/.asoundrc
```

## Release

Push a tag matching the workspace version in `Cargo.toml` (currently `0.14.12`):

```bash
git tag v0.14.12 && git push origin v0.14.12
```

CI then builds and attaches every bundle in the table above. Mobile jobs cannot
hold the desktop bundles back: if one fails, the release publishes without it.
